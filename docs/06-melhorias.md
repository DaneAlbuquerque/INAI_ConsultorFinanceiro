# 🚀 Melhorias futuras

## 1. Otimização do tempo de resposta

Durante os testes, foi observado um tempo elevado entre o envio da pergunta e o retorno da IA. Como evolução do projeto, pretende-se otimizar o fluxo de comunicação com o modelo e avaliar estratégias para reduzir a latência.

## 2. Estratégia de disponibilidade e consumo da API

Durante os testes com usuários, foi atingido o limite de utilização da API do modelo, impedindo a continuidade dos testes planejados. Como melhoria futura, pretende-se avaliar uma estratégia de gerenciamento de consumo e disponibilidade mais adequada para demonstrações e uso por múltiplos usuários.

## 3. Ampliação dos testes com usuários

Foi elaborado um roteiro de avaliação e planejada a participação de usuários externos para coleta de feedback sobre usabilidade e qualidade das respostas. Entretanto, a limitação de utilização da API impediu a conclusão dessa etapa. Os materiais e registros produzidos durante o planejamento e os testes realizados serão mantidos como parte da documentação do projeto.
